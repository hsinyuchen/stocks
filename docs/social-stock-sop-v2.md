### 0.4 名詞澄清：「社交套利」不是無風險套利

本文所稱「社交套利」是方便溝通的自訂用語，實際意思是：

> 觀察產品、產業敘事、社群熱度、媒體關注度是否早於股價與法人資金反應。

它不是金融學意義上的無風險套利。這類策略屬於方向性押注，可能判斷錯誤、買在高點、遇到流動性惡化或題材落空。

### 0.5 Claude 審查後的核心修正原則

之後使用這套能力時，所有個股或主題結論都應符合以下原則：

- **查不到就寫資料不足**，不可用猜測補洞。
- **社群熱度不能單獨成立投資結論**，必須有產品、營收、訂單、法說或官方資料佐證。
- **短線建議必須附可交易性檢查**，包含流動性、注意股 / 處置股、成交量與停損可執行性。
- **評級必須同時附信心等級**。低信心 A 級，應視同 B 級處理。
- **所有前瞻性判斷都要附反證點**，例如哪個營收、財報、價位或新聞會推翻原本 thesis。

## 1. 核心能力總覽

這套能力分成兩大類：

1. **社交選股 / 社交套利選股**
   - 從新聞、社群、產品熱度、通路變化、產業敘事中尋找還沒被股價完全反映的早期訊號。

2. **單一個股深度分析**
   - 針對指定股票，整合基本面、籌碼面、技術面、產業題材、產品實際落地、社群熱度與交易策略。

## 2. 可以做到什麼

### 2.1 個股基本分析

可分析：

- 公司主要業務與產品線
- 最新股價、成交量、均線位置
- 月營收、年增率、累計營收
- EPS、毛利率、營益率、淨利率
- PE、PB、殖利率、市值
- 最新新聞、公告、法說會重點
- 法人買賣超、主力進出、籌碼方向
- 技術型態、支撐、壓力、停損、停利

---

### 2.2 未來發展性 / 爆發性分析

可判斷：

- 未來 6–24 個月是否有重新估值空間
- 公司是否從舊業務轉型到新成長曲線
- 是否受惠於 AI、機器人、車用、軍工、航太、低軌衛星、CPO、電力、資料中心等主題
- 營收成長是否已經開始兌現
- EPS / 毛利率是否跟上營收成長
- 題材是否只是新聞敘事，還是已經進入產品 / 訂單 / 財報

---

### 2.3 社交套利分析

社交套利重點不是單純看社群很熱，而是判斷：

> **市場關注度、產品熱度、產業敘事，是否領先於股價與法人反應。**

會觀察：

- Google News / Yahoo / 鉅亨 / 經濟日報 / 自由財經等新聞熱度
- YouTube 財經節目與標題是否開始密集提到
- X / Reddit / Threads / FB / IG 的公開訊號
- PTT / Dcard / 投資社群是否有討論升溫
- 公司官網、新聞稿、展會、法說是否開始強推新產品
- 電商 / 通路是否有銷售、評價、排行、缺貨、價格變化等訊號

最後會分類為：

| 類型 | 說明 |
|---|---|
| 早期社交套利 | 產品或產業訊號升溫，但股價與法人尚未完全反映 |
| 已部分反映 | 股價已有上漲，但題材仍可能延續 |
| 已高度反映 | 股價、媒體、社群都已很熱，追價風險高 |
| 假訊號 / 雜訊 | 社群很吵但產品、營收、訂單沒有跟上 |
| 資料不足 | 公開資料不足，不能硬判斷 |

---

### 2.4 產品 / 通路 / 社群熱度觀察

會依公司型態分不同方法。

#### A. 消費型公司

例如品牌、電商、手機、穿戴裝置、遊戲、食品、零售等。

可觀察：

- Amazon、momo、PChome、蝦皮、Yahoo 購物等商品頁
- 商品數量、評價數、銷售排行
- 缺貨、補貨、價格變化
- YouTube / TikTok / IG / Threads 討論熱度
- 消費者是否真的在買，而不是只有投資圈在炒

#### B. B2B / ODM / 零組件公司

例如佳能 2374 這種 AI 影像 / 光學 ODM 公司。

電商訊號通常較弱，重點改看：

- 公司官網產品頁
- 展會與 Demo，例如 COMPUTEX、Secutech、Smart City Expo
- 法說會提到的新產品 / 新客戶 / 新專案
- 是否取得認證，例如車規、航太、資安、醫療相關認證
- 是否有大客戶、系統整合商、海外品牌合作
- 產業新聞是否反覆提到同一應用場景

## 4. 單一個股分析框架

之後問單一個股時，可用以下八大模組。

### 1. 基本版個股分析

- 公司做什麼
- 近期股價
- 財報與營收
- 技術面
- 主要風險

### 2. 未來發展性 / 爆發性分析

- 未來 6–24 個月是否有重估空間
- 是否切入高成長產業
- 是否有新客戶、新產品、新應用
- 是否可能從低估值變成成長股估值

### 3. 社交套利分析

- 社群是否開始討論
- 產品是否有早期熱度
- 財經節目 / YouTube / 投資社群是否升溫
- 股價是否尚未完全反映

### 4. 台美連動分析

台股會補：

- 相關美股
- 相關 ETF
- 海外供應鏈
- ADR / SOX / Nasdaq / 主題股風向

美股會補：

- 台股供應鏈
- 相關台股受惠股
- 產業鏈映射

### 5. 短線交易判斷

- MA20 / MA60 / MA100
- 量能是否放大
- 是否突破平台
- 停損 / 停利
- 隔日或短線操作策略

### 6. 籌碼 / 機構資金判斷

台股：

- 外資
- 投信
- 自營商
- 主力券商
- 融資 / 融券

美股：

- 機構持倉
- short interest
- insider trading
- ETF 資金流

### 7. 綜合評分

會用以下面向打分：

| 項目 | 評估重點 |
|---|---|
| 基本面 | 營收、EPS、毛利率、現金流 |
| 未來性 | 產業趨勢、新產品、新市場 |
| 爆發性 | 是否具備重新估值或主題爆發空間 |
| 社交訊號 | 社群、新聞、產品熱度是否升溫 |
| 籌碼 | 法人、主力、資金流是否支持 |
| 技術面 | 均線、量價、支撐壓力 |
| 估值 | PE、PB、PS、同業比較 |
| 風險 | 題材落空、估值過高、技術轉弱 |

最後給：

- A：優先觀察 / 可積極操作
- B：有機會，但需等買點或確認
- C：題材不足 / 風險偏高 / 暫不碰

### 8. 產品 / 通路 / 社群熱度觀察

輸出格式：

```text
產品/社群熱度：高 / 中 / 低
產品能見度：高 / 中 / 低
電商銷售訊號：強 / 普通 / 弱 / 不適用
社群討論熱度：升溫 / 持平 / 冷 / 資料不足
訊號可信度：高 / 中 / 低
社交套利判斷：早期 / 已反映 / 過熱 / 假訊號 / 資料不足
```

## 5. 社交選股流程

### Step 1：先定義主題

例如：

- AI 眼鏡
- 機器人之眼
- AI 伺服器
- CPO / 光通訊
- 低軌衛星
- 軍工 / 無人機
- 智慧安防
- 車用影像
- 電力基建
- 資料中心散熱

---

### Step 2：建立候選股清單

來源：

- Yahoo / 鉅亨 / Google News
- 概念股清單
- 同業比較
- 供應鏈新聞
- 公司官網與法說會
- 產業展會參展名單
- 美股主題對照

---

### Step 3：分桶

不是所有概念股都一樣，要分成：

| 分桶 | 說明 |
|---|---|
| 核心受惠股 | 產品 / 營收 / 客戶最直接 |
| 延伸受惠股 | 有供應鏈關係，但純度較低 |
| 題材外圍股 | 市場會炒，但基本面連動較弱 |
| 假概念股 | 只有新聞或社群提到，實質連動不足 |

---

### Step 4：打分排序

社交選股不只看熱度，會同時看：

- 題材純度
- 營收是否已開始反映
- EPS / 毛利率是否跟上
- 股價是否還在低位階
- 法人是否開始買
- 技術面是否剛轉強
- 社群 / 新聞是否升溫
- 是否已經過熱

---

### Step 5：找可交易名單

最後輸出：

- A級：最值得追蹤
- B級：有題材但等買點
- C級：偏炒作或不夠純
- 不追 / 避開名單
- Top 3 可交易名單
- 買點、停損、停利、催化劑

## 7. 限制與注意事項

這套能力可以做公開資料研究，但不是無限制全網爬蟲。

### 不能保證完整覆蓋

以下資料常有登入牆或反爬限制：

- FB 全量貼文
- IG 全量貼文
- Threads 搜尋結果
- X 全量歷史貼文
- 私人社團
- 電商後台銷售數字
- 付費研報

### 正確做法

採用：

> **公開資料抽樣 + 多來源交叉驗證 + 信心分級**

如果查不到，會標示：

- `資料不足`
- `公開熱度不足`
- `只能作為低信心旁證`
- `不適合用電商訊號判斷`

不會把查不到的東西硬編成結論。

## 8. 推薦提示詞

### 8.1 單一個股深度研究

```text
幫我深度研究 2374 佳能。

請用完整框架，不只看股價和財報，也要看：
1. 公司產品與實際應用
2. 最新營收、EPS、毛利率、估值
3. 法人籌碼、融資、技術面
4. 近 3–6 個月新聞與產業催化劑
5. 相關美股 / ETF / 同業對照
6. 產品行銷、電商、社群熱度，如果查不到請明確標示資料不足
7. 判斷是否有社交套利、未來爆發性或只是題材炒作

最後請給：
- 投資結論：買 / 等 / 續抱 / 減碼 / 避開
- A/B/C 評級
- 短線買點、停損、停利
- 中期 6–24 個月發展性
- 最大風險與反證點
```

### 8.2 社交套利研究

```text
幫我研究 2374 佳能有沒有社交套利機會。

請特別深入看：
1. 實際產品、客戶、應用場景
2. 公司官網、新聞稿、展會、產品行銷
3. 電商或通路能不能看到相關產品熱度
4. YouTube、X、Reddit、Threads、FB/IG公開資料是否有討論升溫
5. 是投資圈在炒，還是真的有消費者/產業端熱度
6. 這些訊號目前是否已反映在股價、成交量、法人籌碼裡

請最後用這個格式：
- 產品能見度：高 / 中 / 低
- 社群熱度：升溫 / 持平 / 冷 / 資料不足
- 電商/通路訊號：強 / 普通 / 弱 / 不適用
- 社交套利判斷：早期 / 已反映 / 過熱 / 假訊號
- 股價是否已經反映：未反映 / 部分反映 / 過度反映
- 操作建議：可追 / 等拉回 / 只觀察 / 避開
```

### 8.3 主題型社交選股

```text
幫我深度研究「AI眼鏡」台股受惠股。

請不要只列概念股，要分成：
1. 核心受惠股
2. 延伸受惠股
3. 題材外圍股
4. 只是被市場亂貼標籤的股票

請同時看：
- 相關美股 / ETF / 海外供應鏈
- 台股公司產品是否真的切入
- 最近 3–6 個月新聞、法說、營收變化
- 法人籌碼與技術面
- 社群、電商、消費端熱度
- 哪些股票已經漲太多，哪些還在低位階
```

### 11.3 評分規則與 A/B/C 評級

#### 11.3.1 八大面向

| 面向 | 權重 | 評估重點 |
|---|---:|---|
| 基本面 | 20% | 營收、EPS、毛利率、現金流、財報品質 |
| 未來性 | 15% | 新產品、新客戶、新市場、產業趨勢 |
| 爆發性 | 10% | 是否具重新估值、主題擴散、訂單放量可能 |
| 社交 / 產品訊號 | 10% | 產品熱度、社群討論、新聞敘事、展會能見度 |
| 籌碼 | 15% | 法人、主力、融資、ETF / 機構資金 |
| 技術面 | 10% | 均線、量價、支撐壓力、趨勢結構 |
| 估值 | 15% | PE、PB、PS、同業比較、成長性是否支撐估值 |
| 風險扣分 | -15% | 題材落空、流動性、估值過熱、法遵、財報疑慮 |

#### 11.3.2 評級閾值

| 分數 | 評級 | 解讀 |
|---:|---|---|
| 75 以上 | A | 高優先追蹤，但仍需通過可交易性檢查 |
| 55–74 | B | 有機會，但需等待價位、催化劑或更多驗證 |
| 55 以下 | C | 暫不列為主力操作標的 |

#### 11.3.3 信心等級

| 信心 | 條件 |
|---|---|
| 高 | 關鍵數據多數來自 T1 / T2，且完成反證搜尋 |
| 中 | 主要數據可靠，但部分題材或社群訊號仍需驗證 |
| 低 | 主要依賴新聞 / 社群 / 推估，或資料不足項過多 |

> 低信心的 A 級，應降為 B 級處理；低信心的 B 級，應只觀察不操作。

#### 11.3.4 一票否決條件

出現以下任一情況，不論總分多高，都應降級或排除：

- 主要題材只有社群聲量，沒有 T1 / T2 佐證。
- 營收、財報與題材方向相反。
- 公司有重大財報疑慮、訴訟、下市或全額交割風險。
- 注意股 / 處置股狀態導致停損不可執行。
- 近 20 日成交量或成交金額不足，進出困難。
- 資料不足面向過多，無法形成可稽核結論。

### 11.4 可交易性硬門檻

進場前必須檢查：

- [ ] 是否為注意股 / 處置股。
- [ ] 是否為全額交割股或特殊風險股。
- [ ] 近 20 日平均成交量是否足以支撐進出。
- [ ] 計畫部位是否小於近 20 日平均成交量的合理比例。
- [ ] 是否可能漲跌停鎖死，導致停損失效。
- [ ] 是否已計入手續費、證交稅、滑價、匯率與複委託成本。
- [ ] 是否有即將公布的重大事件，例如法說、財報、除權息、股東會、處置解除日。

若任何一項無法確認，操作建議應改為：

```text
只觀察，不追價；待可交易性確認後再評估。
```

### 11.5 部位與風險管理

評級不是部位大小。即使評為 A，也要遵守風險上限。

| 項目 | 建議規則 |
|---|---|
| 單筆風險 | 進場價到停損價的最大損失，不超過總資金固定比例 |
| 單檔上限 | 單一股票不可過度集中 |
| 同主題上限 | 同一主題，例如 AI / 機器人 / CPO，需合併計算曝險 |
| 停手線 | 若連續錯誤或月度回撤達門檻，停止新進場並復盤 |
| 相關性檢查 | Top 3 名單若同屬一條供應鏈，視為單一主題曝險 |

### 11.6 社群訊號防操縱規則

社群升溫不一定是利多，也可能是出貨訊號。

常見失真來源：

- KOL 業配
- 投顧群組拉抬
- 水軍與假帳號
- 同質貼文大量洗版
- 股價先漲，社群後追
- 公司或媒體標題過度包裝
- 電商評價被灌水

防守規則：

1. 社群訊號必須搭配 T1 / T2 佐證，否則最高只能給低信心。
2. 若股價已大漲後社群才爆量，應判斷為「已反映 / 過熱」，不是早期套利。
3. 少數帳號貢獻多數討論時，訊號可信度降低。
4. 財經節目與大眾媒體密集討論通常偏中後段訊號，不一定是早期訊號。
5. 只有產品展示、沒有營收 / 訂單 / 毛利率驗證時，不可過度上修評級。

---

### 11.7 社交訊號時序分層

| 階段 | 訊號 | 解讀 |
|---|---|---|
| 早期 | 官網新產品、展會 Demo、認證取得、徵才變化、法說首次提及、小眾專業討論 | 可能具領先性 |
| 中期 | 產業媒體報導、供應鏈新聞、月營收轉折、法人首次覆蓋 | 開始進入市場定價 |
| 晚期 | YouTube 財經節目密集、PTT / Dcard 熱議、標題黨大量出現、股價已急漲 | 追價風險高 |

### 11.8 反證與復盤機制

每次深度研究都應補上：

```text
如果出現以下情況，原 thesis 失效：
1. 月營收低於預期或年增明顯放緩。
2. 毛利率 / EPS 沒跟上營收成長。
3. 法說不再提原本的成長題材。
4. 關鍵產品沒有量產或出貨證據。
5. 股價跌破指定技術防線。
6. 法人連續賣超且量能放大。
7. 同業或美股對照股明顯轉弱。
```

並建立決策紀錄：
